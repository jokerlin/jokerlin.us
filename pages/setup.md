## Development

### AI Agents

Most of my coding now happens through agents in the terminal.

- [Claude Code](https://claude.com/claude-code) - Main coding agent
- [Codex](https://github.com/openai/codex) / [Pi](https://github.com/earendil-works/pi) - Second opinions and experiments
- [Skill Manager](https://github.com/jokerlin/skill-manager) - Sync agent skills and plugins across machines and agents
