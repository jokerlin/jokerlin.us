## 先说策略

号迟早会被封，别指望一个号能一直用下去。只要手头有一套批量注册号且可以退款的机制就行。下面我按手机号、付款、邮箱、开通订阅和日常使用的顺序说说具体做法。内容截至 2026 年 11 月 8 日有效。

风险提示：中国大陆不在 Anthropic 的支持地区里，而且 2026-11-12 生效的新版 Usage Policy 也明确禁止开新号规避封禁。这套做法违反官方条款，大家风险自担。

## 一个稳定的美国手机号

注册美区 Apple ID 得有个能收短信的美国手机号。我用的是 Ultra Mobile，月费 3 美元左右，在闲鱼或者淘宝上就能买到实体卡。

自己手里有这张卡，平时收短信验证码就不用再去折腾接码平台了，稳定很多，用起来也省心。

## 付款：一定要能退款

我对付款方式就一个要求：号被封之后得能退钱。所以我都在 App Store 里走内购，不去网页上订阅。

App Store 付款可以走这两个办法：

1. 美区 PayPal 绑定国内信用卡。
2. 买 Apple 礼品卡充进 Apple 账户。Apple 礼品卡支持银联付款，直接刷国内信用卡就能买。

## 域名邮箱

每开一个新号都得配一个新邮箱，我直接用域名邮箱解决。去腾讯云买个 .asia 域名，首年才 5 块钱人民币，很便宜。

收信这块交给开源项目 HPC.email 托管，随时都能建新的邮箱前缀，邮箱想要多少有多少。

## 开通 Claude 订阅

操作全程在一台登了美区 Apple ID 的 iPhone 上完成。先下载 Claude App，接着按这两步走：

1. 输入邮箱完成验证，去邮箱里收登录链接。
2. 点链接登录。注意千万别选 free trial，直接点升级，选你要的 Pro、Max 或 Ultra。

通常到这一步就能直接扣款成功，运气好的话不用做 KYC。不过现在 KYC 收紧了，付完钱有可能会弹出 KYC。真碰上了也别慌，拿自己的中国护照就能过。这个办法截至 2026 年 11 月 8 日依然管用。

## 日常使用

### IP 要干净

挑一个稍微干净点的机场或者 VPS，倒也不必非上家宽，像搬瓦工这种就够用。但别碰那种规模很大、常被反代中转站拿去跑黑号的机场。

市面上查 IP 纯度的工具不少，我回头整理几个再补上来。

### 不改时区

我平时不改时区。很多系统设置都依赖系统时间，乱改时区很容易耽误正经工作，所以我一直用的都是上海或新加坡时区。

### 只让 Claude 的流量走代理

代理软件用 Clash、Clash Verge、Stash、Surge 都可以。路由规则直接让 AI 帮你写就行，只要确保 Claude 和 Anthropic 相关的域名全都走机场。

我平时既不开 TUN，也不开全局代理。开全局代理太影响日常工作了，比如我手头有些 VPN 的需求就会跟它起冲突。

不过不开 TUN 的话，Claude 桌面端和手机端的流量确实不好管，所以我干脆只用 Claude Code 的 TUI。平时在终端里设好 `HTTP_PROXY` 和 `HTTPS_PROXY`，再搭配我自己写的开源项目 [claude-guard](https://github.com/jokerlin/claude-guard) 一起用。它会在 Claude Code 启动时和每次发 prompt 前检查出口 IP，一旦发现出口 IP 不在白名单里，就会当场拦下来提醒你。

因为不用 Claude 手机端，自带的 remote control 自然也就用不了。我平时都是用 Moshi 这个 App 远程连回电脑上的终端。

### 多台电脑，同一个出口

多台电脑共用一个 Claude 订阅是没问题的，只要设备数量别太多就行。自己平时用的话，5 到 6 台也就到头了。

但有个硬前提：所有电脑必须保持同一个出口 IP，千万不能跳 IP。一旦来回跳 IP，很容易被检测出来，接着就是封号。
